# Digital Rage Room — Army Field Edition

An unofficial Army-inspired digital rage room for IT personnel. Pick a frustration, pull a randomized subject-aware image from Wikimedia Commons with a safe-humor bias, trigger exaggerated destruction effects, and reset with a maximum-rage nuclear-style animation. The field overlay rotates through 111 original Army/IT meme captions.
