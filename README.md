# Digital Rage Room — Army Field Edition

An unofficial Army-inspired digital rage room for IT personnel. Pick a frustration, cycle through harmless photo targets, trigger exaggerated destruction effects, and reset with a maximum-rage nuclear-style animation.

## Live app

https://t3ll3r.github.io/digital-rage-room/

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm test
npm run lint
npm run build
```
